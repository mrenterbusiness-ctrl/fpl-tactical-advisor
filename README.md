# 🏆 أسمع مني — مستشار فانتازي الدوري الإنجليزي الذكي
### إنشاء وتطوير: أحمد سعيد

تطبيق ويب وتطبيق هجين (Hybrid / PWA) متكامل يعمل كمستشار تكتيكي ذكي لمدربي فانتازي الدوري الإنجليزي الممتاز (Fantasy Premier League)، يعتمد على التحليل الإحصائي الدقيق لنخبة مدربي الـ Top 10k، ويدمج الذكاء الاصطناعي (Google Gemini API) لصياغة القرارات وخطط اللعب بأسلوب كبار نقاد ومحللي الاستوديوهات والبودكاستات الكروية.

---

## 🌟 الميزات والمواصفات الفنية المطبقة بالكامل

### 1. الربط مع سيرفرات FPL الرسمية وسحب البيانات بالتوازي:
- سحب بيانات اللعبة واللاعبين من `/api/bootstrap-static/`.
- سحب مواعيد وصعوبة المباريات من `/api/fixtures/`.
- سحب تشكيلة الفريق الحالية من `/api/entry/{team_id}/event/{gw}/picks/`.
- سحب بيانات المدرب والبنك وقيمة التشكيلة من `/api/entry/{team_id}/`.
- سحب خواص الفانتازي المتاحة والمستهلكة من `/api/entry/{team_id}/history/`.
- **سحب سجل أداء اللاعب في آخر 3 مباريات بالتوازي:** استدعاء متزامن وسريع عبر `ThreadPoolExecutor` من `/api/element-summary/{player_id}/` (الدقائق، الأهداف، الأسيستات، الكلين شيت، والنقاط).

### 2. محرك الذكاء الاصطناعي والمحرك الاحتياطي (AI & Fallback Engine):
- ربط مباشر مع أحدث نماذج Google Gemini (مثل `gemini-3-flash-preview` و `gemini-flash-latest`) عبر الترويسة الأمنية الرسمية `x-goog-api-key`.
- محرك إحصائي احتياطي (Rule-based Fallback) محكم بنسبة 100% يولد الخطط الـ 5 كاملة حتى في حال انقطاع الإنترنت أو غياب مفتاح API.
- دعم تعديل مفتاح API عبر واجهة المستخدم وحفظه محلياً في المتصفح.

### 3. المنطق الإحصائي والتكتيكي لحساب النقاط:
- حساب دقيق للنقاط المتوقعة (xP) يراعي: الفورمة، الـ PPG، صعوبة الـ 3 مواجهات (FDR)، الدقائق المتوقعة (xMins)، ركلات الجزاء والضربات الثابتة، والتدوير الأوروبي.
- **عزل نقاط الدكة تماماً (Strict Bench Isolation):** مجموع نقاط الخطة محسوب حصراً من الـ 11 لاعباً أساسياً في التشكيلة النهائية + نقط الكابتن الإضافية (2x). نقاط الدكة معزولة تماماً.
- **عرض النقاط كمدى احتمالي (Floor & Ceiling):** عرض النقط كمدى واقعي (مثل: `62 - 83 نقطة`).

### 4. الخطط التكتيكية الـ 5 المتكاملة:
1. **الخطة 1: الآمنة والمضمونة (Safe & Meta):** لحماية الرتبة، الاعتماد على كابتن آمن ومباراة سهلة مع تبديل آمن أو Roll.
2. **الخطة 2: المخاطرة والديفرنشال (High Risk / High Reward):** كابتن ديفرنشال وخيارات هجومية جريئة لتعويض فارق النقاط.
3. **الخطة 3: توفير الكاش وبناء البنك (Budget & Future Plan):** تسييل سيولة مالية والتحضير لصفقات كبرى قادمة.
4. **الخطة 4: تأمين الدفاع والكلين شيت (Clean Sheet Hunters):** استهداف مدافعين يمتلكون نزعة هجومية بجدول سهل.
5. **الخطة 5: العملية الجراحية (Aggressive Overhaul):** حل أزمات الإصابات ونزول الأسعار بتبديل مزدوج بسالب 4 مدروس أو وايلد كارد.

### 5. هيكل كارت الخطة (Card Architecture):
كل كارت خطة مقسم إلى 7 أقسام متتالية، تحت كل قسم شرحه الفني المستفيض الخاص به:
1. **رأس الكارت (Header):** شارة الخطة، عنوانها، والمدى النقطي للـ 11 أساسياً.
2. **التبديل الموصى به (Transfer):** كارتان متجاوران: (🔴 Out) مقابل (🟢 In) + صندوق شرح وأسباب التبديل الفنية بالتفصيل.
3. **الكابتن والنائب (Captain & Vice):** كارتان متجاوران: (👑 C - 2x) و (🛡️ V) + تحليل مفصل لأسباب الكبتنة وتأمين الفايس من مباراة أخرى.
4. **ورقة الديفرنشال (Differential Pick <= 10%):** فحص دكة الفريق أولاً، أو ترشيح ديفرنشال من السوق وتحديد من يخرج وتوضيح الخيارين + تحليل خيار الديفرنشال.
5. **التشكيلة الأساسية النهائية وترتيب الدكة:** 11 لاعباً أساسياً + دكة البدلاء في 4 مربعات مستقلة (Sub 1, Sub 2, Sub 3، وحارس المرمى منفصل تماماً) + شرح أسباب تنظيم التشكيل وترتيب البدلاء.
6. **نصيحة وسائل المساعدة (Chips Advice).**
7. **رؤى وتنبيهات تكتيكية ذكية (AI Insights):** صندوق بنفسجي لتحذيرات تقلبات الأسعار الليلة واستشراف الجولات القادمة.

### 6. دعم التطبيق الهجين (Hybrid App / PWA):
- يدعم التثبيت المباشر على الهاتف (Android / iOS) والكمبيوتر كـ Progressive Web App.
- مزود بـ `manifest.json` و Service Worker (`sw.js`) للتخزين المحلي والتشغيل السريع.

## 🚀 طريقة التشغيل

### تشغيل فوري بنقرة واحدة (Windows):
اضغط مرتين على ملف:
```text
تشغيل_الموقع.bat
```
سيتم تشغيل السيرفر وفتح المتصفح تلقائياً على الرابط: `http://localhost:8000`.

### أو عبر سطر الأوامر (Terminal):
```bash
python standalone_server.py
```
أو عبر Flask:
```bash
pip install -r requirements.txt
python app.py
```
